## About the project

DarkVisionOA is a modding framework for the Discord desktop client on Windows. It is a fork of OpenAsar and an addon for Vencord. It bundles Vencord and Equicord (Vencord fork) into one system (can be disabled). DVOA can run larger and more complex plugins than either of them. The core stays small, and additional content is downloaded from GitHub or other sources.

DVOA is built for modders and developers who want to quickly add fast and easy plugins or test patches with little effort. It is not a replacement for OpenAsar.

## Questions

- Tell the user that the project is still in development.
